Production RAG · Evals · LLM-as-a-Judge

A support agent that knows when not to answer.

For every customer message it classifies the intent, drafts a reply grounded in how the brand actually resolved similar cases, and decides whether a human must handle it. Most of the work is the evaluation harness that proves it is safe to deploy.

Try the live demo → View the code Waking the demo server…

The demo runs on Cloud Run and scales to zero when idle, so the first request takes up to a minute. This page starts it for you as soon as you arrive.

What it does

Built and evaluated on ~40k real SpotifyCares conversations from the Kaggle Customer Support on Twitter dataset.

01 · Classify

Assigns one of 11 intents, derived from the data with KMeans clustering.

02 · Retrieve

Finds the 5 most similar past tickets among 33,838 historical customer → agent exchanges.

03 · Draft

Writes a reply grounded in how the brand actually resolved those cases.

04 · Route

Auto-handles or escalates to a human, with one of 6 named escalation reasons.

Findings worth more than the headline numbers

The development stand-in model overstated safety: swapping in the real model moved escalation recall from 86.4% to 81.8%, replicated on an independent 250-message split.

AI-generated labels flattered the agent by ~10 points, caught by a blind control group. And sharpening the escalation definition moved precision from 64% to 78% with predictions unchanged.

Guardrails and production engineering

The safety layer is deliberately not LLM-based: it is the part you least want to be probabilistic.

  • Prompt-injection screening before the model sees the text
  • Luhn-validated card, email and phone redaction
  • Blocks drafts claiming actions the agent cannot take
  • 25 adversarial red-team cases, green in CI
  • FastAPI on Cloud Run, scale-to-zero, 1.3s warm latency
  • Gemini on Vertex AI via service account, no API key anywhere
  • Circuit breaker, backoff, graceful fallback to a human
  • Rate limiting, spend caps, Prometheus metrics, 77 tests
